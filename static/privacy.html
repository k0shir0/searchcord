Privacy & data

Searchcord stores your archived message text, image links, server and channel names, author identities, and scrape progress in your configured local SQLite database. Expanded profile collection is optional. Your Discord token, if saved, is stored in that database too.

Treat your database, exports, and backups as private files. Searchcord does not encrypt them or provide account authentication.

Network connections

Connecting Discord, scraping, and live monitoring use Discord’s API. Search works on the local archive without a token. Indexed profile avatars load from Discord’s CDN. Opening an image can refresh its link through Discord before redirecting your browser. The Stats view uses Chart.js loaded from jsDelivr.

Retention & deletion

Archived data remains until you remove it. Settings → Clear All Data deletes archived messages and associated index and profile records from the active database, retaining settings such as your saved token. It does not remove exports, backups, or copies. Deleting messages from Discord is a separate action in the DMs view.

Local access

The server binds to loopback by default. Anyone with access to the server or database can access private archive data. Browser search URLs include the query and selected filters; avoid sharing them if those details are private.

These notes describe the local application. They are not a policy for a hosted service.
