# Searchcord logo

Option A, selected on 2026-10-02: menu-blue symbol (`#8abde8`), mint Cord
(`#8dd8b0`), real Arial Bold lettering. Search uses navy `#0b2548` on light
backgrounds and pale `#edf3f8` on dark backgrounds.

- `searchcord-logo.png`: transparent light-background version.
- `searchcord-logo-dark.png`: transparent dark-background version.
- Both are 1920 x 440 PNGs, rendered by Chrome from the approved report's
  `exportTrial('a')` function. PNGs preserve the actual Arial Bold glyphs without
  depending on fonts installed on the viewer's machine.
- Editable symbol and text source: `../../review/2026-10-02/logo-trial-a.svg`.
  The SVG contains a raster symbol mask and editable real-font text. It does
  not bundle font files.

The README selects the appropriate variant with a picture element. Keep the
aspect ratio and use a plain background. The in-app wordmark remains unchanged.

Public comparison found related chat/search marks, but no confirmed exact
company match. This selection does not establish exclusive ownership or
trademark clearance. Research and both original trials are retained in
`../../review/2026-10-02/index.html`.
